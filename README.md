# TPI-OE
Trabajo practico Integrador - Organizacion Empresarial

Se propone una implementación de Modulo Central de tipo ERP (Planificador de Recursos
Empresariales), el cual se encargaría de la interacción entre distintas dependencias de la
hamburguesería, conectando las entradas de pedidos, con el control operativo, financiero y
tambien el inventario en tiempo real.

Declaración de Uso de IA:
Se certifica que en la presente entrega se utilizó una herramienta de IA Generativa (Google Gemini) para sugerencias en el modelado del
BPMN, a modo de corrección en el cual se estaba actualmente trabajando. El contenido proporcionado fue revisado con criterio, corregido y
aprobado por el autor, quien asume responsabilidad del trabajo presentado.
